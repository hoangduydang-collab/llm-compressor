01 / ObjectiveServe the 4-bit model on a faster kernel — without lowering the evidence bar

The in-house GPTQ model served correctly but left speed on the table. Humming's W4A8 kernel promised more; the goal was to adopt it only after it passed the same fail-closed checks as everything else we ship.

  • 7a · Qualified — backend attestation, correctness, stability wk Jul 20–26
  • 7b · Adopted — ~34% faster for a single user; now the default kernel wk Jul 20–26

02 / ResultQualified, then adopted

The qualified stack keeps the model's 4-bit weights packed in GPU memory and computes on 8-bit activations, with all production serving features on (multi-GPU parallelism, CUDA graphs). A fail-closed attestation proves at serve time that the intended kernel actually ran — the fast path cannot be silently swapped out or silently absent.

Why this was gated

A faster kernel that returns wrong numbers is a regression, not a win. Qualification required correctness against the reference kernel, stability under load, and the attestation above — only then did the benchmark comparison count.
