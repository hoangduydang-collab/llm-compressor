The current goals, and where each one stands

A single north star split into six long-term goals. Three are active enough to carry their own field note; the rest are folded in or held for later. This page is the index.

Fork of llm-compressor MiniMax-M3 case study Source: PROJECT_GOALS.md

The hard part of automatic quantization is not choosing four bits instead of sixteen. It is making a new model architecture, a quantization algorithm, and an inference engine agree on the same contract — then proving, with evidence, that the agreement held.

Our fork of llm-compressor is the control plane for that agreement, with MiniMax-M3 as the first case study. The durable, repo-authoritative list of goals lives in PROJECT_GOALS.md (last reviewed 2026-07-19). This overview reproduces that list and links each active goal to its own detailed page. Everything here is scoped to evidence already in the repository.

The listSix long-term goals

Goal 01

Fast parallel quantization

Parallelize AWQ and GPTQ calibration to bring a full MiniMax-M3 quantization run into a 4–8 hour window, using the fork's built-in distributed path rather than bespoke expert-parallel code.

Work in progressOpen field note →
 Goal 02

Temporary evaluation pipeline

A hash-locked, fail-closed harness to compare our in-house quant against other quants and the BF16 baseline — a stopgap that produces trustworthy model-to-model decisions while an official pipeline is built later.

Work in progressOpen field note →
 Goal 06

Packed NVFP4 W4A8 on Hopper

Run official NVFP4 checkpoints on H100/H200 with weights kept packed at four bits, dynamic FP8 activations, and in-kernel E2M1→FP8 conversion feeding FP8 Tensor Cores — a benchmark-gated systems investigation.

Planned · benchmark-gatedOpen field note →
Goal 03

Working AWQ quantized model

Produce a correct AWQ-quantized MiniMax-M3 by fixing the current AWQ defect. Tracked alongside Goal 1 — the distributed AWQ path is where the fix is landing.

After / with Goal 1
Goal 04

Generalize to any quant method

Extend the pipeline beyond AWQ and GPTQ to arbitrary quantization methods.

Future work
Goal 05

Generalize gates to any model family

Generalize the serving-ABI gate and the pre-quantization static gate so they apply to any model family, not just MiniMax-M3.

Future work
