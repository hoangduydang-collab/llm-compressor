## Native and baseline/runtime limitations

- `pipeline.validate_glm53_ep_gptq` hard-requires CT `weight_packed`, `weight_scale`, `weight_shape`. Native output deliberately uses different names/layout; this validator will fail a valid native checkpoint.
- `pipeline.compare_glm53_ep_gptq` loads checkpoints through Transformers `AutoModelForCausalLM.from_pretrained` onto GPU 0. It does not implement native SGLang W4AFP8 loading. Its `compare_logit_arrays` helper is reusable on already captured arrays, but the old CLI is not a native runtime comparison.
- `pipeline.verify_sglang_w4afp8` compares a CT source checkpoint to a converted destination; direct save intentionally creates no intermediate CT checkpoint. Use the new manifest verifier instead of inventing a missing source artifact.
- Historical serving guide uses mutable image tag `lmsysorg/sglang:v0.5.17`, `--quantization w4afp8`, `--disable-shared-experts-fusion`, TP8, and full-model checkpoints. This is a runtime precedent, not a digest-pinned five-layer load/forward smoke contract. Pin and verify an actual runtime, launch flags, tokenizer, fixed input IDs, output/logit capture method and finite-output gate before including runtime qualification in an executable packet. Do not graft MTP or enable speculative decoding.
- New CPU evidence explicitly leaves activation-enabled DDP/EP equivalence unqualified: max relative Frobenius error 0.312%, exceeding the old pointwise tolerance in that fixture. Do not silently relax `rtol=2e-3, atol=2e-4`, assume weight-only equivalence proves activation/runtime equivalence, or call hash conformance a quality pass.
- If DDP4 is included, run the **same new recipe** with EP disabled and Hessian offload enabled, preserve the same calibration bytes/tokenization, and define a native-compatible capture/comparison gate first. EP4/EP8-only success establishes distributed execution, serialization and measured resources; it does not create a paired accuracy baseline. A quality claim requires a separately specified matched baseline/evaluation contract. Existing full-model W4A16 or MTP-containing checkpoints are not interchangeable representative controls.
