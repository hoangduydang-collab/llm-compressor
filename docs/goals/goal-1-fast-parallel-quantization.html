Goal 01 / engineering field note · Work in progress

Fast parallel quantization

The core target landed: distributed AWQ met the 4–8 hour window with a 7 h 22 m full run, and the DDP path has since been proven on a second model and a third quant method (AutoRound, 30B MoE in 1 h 40 m). One sub-task remains open — distributed save/export. Checkpoint quality itself belongs to Goal 3 and Goal 2, not parallelization.

Target: full run in 4–8 h AWQ + GPTQ MiniMax-M3 · ~450–460B params

01 / ObjectiveFull quantization within one working session

The target is a complete MiniMax-M3 AWQ or GPTQ run in 4–8 hours, including a saved checkpoint that survives correctness gates.

The implementation uses the fork's existing distributed calibration paths: AWQ shares calibration statistics across ranks, GPTQ distributes modules, and disk offload keeps host memory bounded. This is now the production direction for both methods.

  • 1a · Distributed AWQ/GPTQ calibration path — full AWQ run, all gates green, 7 h 22 m on one 8×H100 node wk Jul 20–26
  • 1b · DDP rank-partition correctness fix — the partition was applied to a local variable only, so all ranks had calibrated on the same rows (ddd4f9f9) wk Jul 27–Aug 02
  • 1c · Proven beyond M3 and beyond AWQ/GPTQ — 8×H100 DDP AutoRound quantized Qwen3-30B-A3B (W2A16) end to end in 1 h 40 m wk Jul 27–Aug 02
  • 1d · Distributed save/export — improve the save/export portion of distributed quantization

02 / Full-calibration resultThe time target is met, and the checkpoint passed its gates

The full-calibration AWQ run quantized end-to-end in 7 h 22 m on one 8×H100 node — about 19 min to load, 6 h 40 m of calibration (≈7 min per layer across all 57 MoE layers), and 19 min to save plus run the in-line gates — covering all 21,888 routed-expert Linears and landing inside the 4–8 hour target.

Observed in this fork The artifact landed and passed every gate

The checkpoint cleared every fail-closed gate (smoothing-scale fold on all 57 layers, plus quant-verify and dequant sampling on the riskiest layers), served coherent chat on single-node vLLM TP8, and passed Goal 2's smoke evaluation (ready_for_production: true). An earlier run had been rejected by these gates: AWQ's scale search had inflated smoothing scales by ~100× on dead (zero-activation) norm channels in five layers. The dead-channel fix (commit e87eef77), with a related qparam-broadcast fix (25a0324d), resolved it — both are candidates to contribute back upstream to llm-compressor.

03 / BoundaryCheckpoint correctness is Goal 3 — and it landed too

The headline sub-task (1a) is complete because the distributed path demonstrated full calibration inside the target window; the goal stays open on sub-task 1d (distributed save/export). Producing a correct, gate-passing AWQ checkpoint is Goal 3's contract, not a parallelization-throughput question.

As of 2026-07-20 that is also done: the dead-channel scale fix and the corrected full run yielded an accepted artifact. Its quality against the BF16 baseline is measured under Goal 2's production evaluation.
