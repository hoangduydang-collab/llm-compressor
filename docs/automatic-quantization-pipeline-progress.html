The current goals, and where each one stands

Seven long-term goals with clear boundaries: the in-house AWQ checkpoint (Goal 3) is quality-competitive since 2026-07-23, native Humming W4A8 serving (Goal 7) landed 2026-07-26, and the pipeline is now generalizing — a third quant method (Goal 4) and a second model family are in flight alongside the evaluation pipeline (Goal 2).

The hard part of automatic quantization is not choosing four bits instead of sixteen. It is making a new model architecture, a quantization algorithm, and an inference engine agree on the same contract — then proving, with evidence, that the agreement held.

Our fork of llm-compressor is the control plane for that agreement, with MiniMax-M3 as the first case study. The durable goal definitions live in PROJECT_GOALS.md; this overview presents the current research-update boundaries and links the goals with dedicated field notes. Everything here is scoped to evidence already in the repository.

Each goal carries an explicit sub-task list — the unit of progress. New sub-tasks may be added to a goal at any time without rewriting its history; every finished sub-task is stamped with the week it landed, so weekly achievement reads directly off the cards.
